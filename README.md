# BookStore

A React web app for managing and browsing a bookstore.

## Features

- Registration and login
- Book list with add and edit forms
- Category management
- User list
- Shopping cart

## Tech stack

React 18 · Vite · React Router · Tailwind CSS · Material UI · Formik · Yup · Axios

## Run locally

```bash
cd Project
npm install
npm run dev
```

The app needs a separate backend API, which is not part of this repository. Its address is set in `Project/src/services/constants.js` (the login page also has it written directly).
